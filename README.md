# AliceLand — б/у карнавальні костюми

## Як це працює
- **Сайт** — `public/index.html`. Каталог береться з `/api/products`.
- **Адмінка** — `/admin/`. Вхід за паролем із змінної `ADMIN_PASSWORD` у Netlify.
- **Дані** лежать у Netlify Blobs, а не в репозиторії. Новий костюм з'являється на сайті одразу
  і не запускає перебудову (кожна перебудова на безкоштовному плані коштує 15 із 300 кредитів на місяць).
- **Замовлення** — `netlify/functions/order.js` надсилає їх у Telegram-бота.

## Змінні в Netlify (Project configuration → Environment variables)
| Змінна | Що це |
|---|---|
| `ADMIN_PASSWORD` | довгий пароль для адмінки (можна українськими літерами) |
| `TG_BOT_TOKEN` | токен Telegram-бота (лише тут, ніколи в файлах репозиторію) |
| `TG_CHAT_ID` | id чату, куди приходять замовлення |

Після зміни змінних треба зробити новий деплой (Deploys → Trigger deploy).

## Структура
```
public/                 сайт: index.html, logo.jpg, admin/index.html
netlify/functions/      api.mjs (каталог, фото, адмінка), order.js (замовлення)
package.json            залежність @netlify/blobs
netlify.toml            Netlify публікує папку public
```

## Корисно знати
- Артикули видаються самі: ALC-001, ALC-002 і далі. Той самий артикул на сайті, в адмінці й у замовленні.
- «Продано» знімає лот із сайту, але він лишається в адмінці. Прибрати його в Instagram і на Shafa треба вручну.
- Резервна копія: Адмінка → Налаштування → «Зберегти копію каталогу» (файл без фото).
- Каталог і фото спільні для всіх розгортань цього сайту, зокрема для пробних гілок і прев'ю.
  Адмінка на прев'ю змінює справжній каталог.
- Посилання на лот: `/?art=ALC-001`.

## Прибрати зі старої версії
У корені репозиторію вже не потрібні: `index.html`, `admin/`, `products.json`, `order.js`,
`aliceland-github (1).zip`. У старому `index.html` і в zip лежить токен бота: після `/revoke` він
не діє, але файли краще видалити.
